# Klingon

**单文件认知与输出系统。** 一个 `index.html`，你的浏览器，你的数据——无需构建、无框架、无后端、无账号。

## 背景

Klingon 以**桦泽紫苑式输出法**为骨架：**D1** 直觉留痕（一句话捕捉灵感）→ **D3** 转化书写（展开成反思）→ **D7** 沉淀实践（化为行动），构成一条温和的 7 日记忆回路。晨间三件聚焦开启多巴胺，晚间三行微反思收束一天，月底所有记录自动沉淀成册。

它同时也是一次「**少即是多**」的软件实验：全站只允许一种强调色、零彩色 emoji、不叠弹窗——只有温润纸白、衬线字体与轻微的声音反馈。它被设计成「真的可以每天用」的工具，因此**绝不责备你落下的任何一天**（记忆宽容期）。

## 功能

- **晨间待办** — 最多 3 件聚焦事项，朝阳徽章随完成数升起；支持拖拽排序；昨晚写下的「明天最想迈出的一小步」会化作幽灵水印，按 Tab 即可采纳。
- **输出追踪** — 杂志式卡片搭配打孔票根（STUB 01 已显影 → STUB 02 今日待打孔 → STUB 03 锁定），完成阶段即在票根盖上红色 PUNCHED 钢印；无边框写作抽屉严格保留你的每一个换行与分段。
- **晚思复盘** — 今日留痕轻量折叠呈现；三行微反思即时存档；4-7-8 呼吸节律；熄灯时响起合成颂钵。
- **月度双手账** — 30 天生命星图与节律达成率；晨间行动／晚思心灵双本切换；出版级 A4 PDF 导出（左侧装订边距，同日内容绝不跨页斩断）。
- **全局检索** — `Ctrl / ⌘ + K` 搜索你写下的所有内容。
- **多窗口安全存储** — 写入前自动合并多窗口改动；删除墓碑防止复活；「顺序即数据」；每次保存留存时间戳备份（最多 20 个还原点）；快照救援与历史版本面板。
- **本地存档** — 可选授权一个文件夹，每次保存同步写入明文 `klingon-data.json`；即使浏览器数据被清空，下次打开自动复原。
- **导出** — 纸白／曜石双主题分享卡（复制或下载 PNG）；整库 JSON 备份／恢复。

## 设计原则

- 全站零彩色 emoji，所有图标皆为 1.5px 单色几何线条。
- 分类标签恒为英文：**All · Book · Movie · Show · Podcast · Life**。
- 长文永远保留换行与分段：`pre-wrap`、Georgia 衬线体、1.8 行高。
- 写作区域物理级去框，聚焦时仅保留下划线。
- 温润纸白调色板：`#FBFAF4` 纸面 · `#F8F7F0` 侧栏 · `#E6E2D4` 米白 · `#20808D` 绿松石强调色。

## 使用方式

1. 下载 `index.html`
2. 直接双击打开（建议 Chrome 或 Edge）
3. 就这样。

可选：点击侧栏「啟用本地存檔」按钮，将每次保存同步到你指定的文件夹。

## 数据与隐私

所有数据只存在你的浏览器 localStorage（键值 `klingon.v1`）与你指定的本地文件夹中，**永不上传任何服务器**。页面唯一的网络请求是由 CDN 加载 html2canvas；包括图片导出在内的所有功能皆可离线运行。
